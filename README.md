# 🎵 Spotify Clone

A responsive **Spotify-inspired music player** built using **HTML, CSS, and JavaScript**. This project recreates the core interface and music-playing experience of Spotify with custom playlists, song navigation, audio controls, and autoplay functionality.

## 🚀 Live Demo

**Live Demo:** https://bxodelroy.github.io/Spotify-Clone/

## 📌 Features

* 🎵 Spotify-inspired user interface
* 🎧 Music playback using JavaScript
* ⏭️ Previous and next song controls
* ▶️ Play and pause functionality
* 🔄 Automatic song playback
* 🔊 Volume control
* 📋 Multiple playlists
* 🎶 Song selection from playlists
* 📱 Responsive layout
* 🎨 Custom styling inspired by Spotify

## 🎼 Available Playlists

The project currently includes:

* **Rock Core**
* **Bollywood Core**
* **Hollywood Hits**
* **Lana Core**

## 🛠️ Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Styling, layout, and responsive design
* **JavaScript** – Music player functionality and application logic

## 🎮 Music Player Functionality

The player maintains the current playback state using JavaScript, including:

* Current song index
* Audio element/state
* Autoplay state
* Volume level
* Playlist/song information

Users can select songs from playlists and control playback directly through the player interface.

## 💻 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/bxodelroy/Spotify-Clone.git
```

2. Open the project folder:

```bash
cd Spotify-Clone
```

3. Open `index.html` in your browser.

No additional dependencies or installation are required.
